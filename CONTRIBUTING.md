\# Contributing



\## Development Workflow



1\. Create or select the appropriate feature branch.

2\. Implement the change.

3\. Add or update tests.

4\. Run relevant tests locally.

5\. Review the changes.

6\. Create a Git commit using a conventional commit message.

7\. Push the branch to GitHub.



\## Branches



The project uses:



\- `main` — stable code

\- `develop` — integration branch

\- `feature/\*` — new functionality

\- `bugfix/\*` — bug fixes

\- `hotfix/\*` — urgent production fixes



\## Commit Format



Commits should follow a conventional format such as:



```text

feat: add interview session model

fix: correct answer persistence

test: add interview service tests

docs: update architecture documentation
