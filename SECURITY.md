\# Security



Security and privacy are core requirements of the AI Interviewer Platform.



\## Principles



\- Never commit API keys or credentials.

\- Store secrets using environment variables locally.

\- Validate user input.

\- Implement authentication and role-based authorization.

\- Protect candidate interview data.

\- Maintain appropriate audit logs.

\- Apply secure storage practices.

\- Minimize unnecessary candidate data collection.

\- Support appropriate data retention and deletion.

\- Obtain required consent for recording and monitoring features.



\## AI Safety



The system should provide decision support rather than automatically making high-impact hiring decisions.



The system should not infer protected characteristics or make unsupported personality judgments.



Consistency analysis should identify evidence and potential discrepancies rather than automatically accusing candidates of cheating.
